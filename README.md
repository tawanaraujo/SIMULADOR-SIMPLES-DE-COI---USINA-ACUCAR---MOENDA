# SIMULADOR-SIMPLES-DE-COI---USINA-AÇUCAR---MOENDA
Simulador extremamente básico de controle de motores e automação em usina de cana de açucar

ESTE É UM SIMULADOR SIMPLES COM CONTROLE MUITO SIMPLES DE MOTORES E FOI FEITO PURAMENTE PARA APRIMORAÇÃO DE CONCEITOS SOBRE MECANICA, FISICA, AUTOMAÇÃO E SOBRE TUDO A PROGRAMAÇÃO EM PYTHON UTILIZANDO A BIBLIOTECA PYGAME.

DICAS:
BOTÃO DE POTÊNCIA AINDA NÃO FUNCIONA
BOTÃO ON = LIGA MOTORES
BOTÃO OFF = DESLIGA MOTORES
BOTÃO SHUT = FUNCIONA COMO UMA ESPECIE DE EMERGENCIA QUE NO FUTURO VAI REINICIAR OS PARAMETROS DOS MOTORES DE FORMA SEGURA

*A JANELA FECHARÁ AO CLICAR ESC
*INSTALE A BIBLIOTECA PYGAME
